            Delivery, tuning and service
            
      
              
              
              
              
              
              
              
              
              
              
              
              
            
      
            
      SID: 1-65535. PIDs: 0-8191; blank optional PIDs are omitted. All audio PIDs are retained.
      
            
      
            
      
            
      Empty primary tuning inherits Advanced, then card defaults. Auto is an explicit override, not inheritance. ISI must be decimal 0-255 for DVB-S2; DVB-S needs no effective ISI, including inherited values. Card inventory is a snapshot, not proof of future placement or tuning.
      
            
      
          
      
          
      
            Adapter and RF
            
      
              
              
            
      
            
      
            
      
              
              
      
                
                
      
                  
                  
                  
                  
                
      
                
      
                  
                  
                
      
                
                
      Unicable I: slots 1-8, positions A-B; Unicable II: slots 1-32, positions A-D. Standard LNB modes support positions A-D. RF frequencies stay in MHz. Hidden oscillator values are retained. No additional DiSEqC commands are configured here.
      
              
      
            
      
          
      
          
      
            Output
            
            
            
      
              
              
              
              
              
              
              
              
              
              
            
      
            
      
              
              
            
      
            
            
      HTTP and SRT defaults use the loaded server play ports. An untouched output keeps its exact original URL. Changing output fields rebuilds it, including replacing unrepresented URL parameters. Secrets are hidden in the preview.
      
            
          
      
          
      
            Descrambling
            
      
              
              
              
              
              
              
            
      
            
      Enter the provider explicitly; it is not inferred from CA descriptors. Leave ECM PID empty only for an unambiguous matching route. Selecting a profile or PID does not enable descrambling.
      
            
      Changing an active policy discards pending keys and media for that service. These controls do not request an adapter restart.
